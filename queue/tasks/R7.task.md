## Промт исполнителя

Правишь ровно один файл: `$MNEMAZINE_HOME/tests/test-coverage-fix.mjs`.
Каталог `$MNEMAZINE_HOME/scripts/` — ТОЛЬКО ЧТЕНИЕ, туда писать запрещено.
Сам конвейер `$MNEMAZINE_HOME/workflows/mnemazina-pipeline.js` не трогать.

Основание — `локальный файл ремонта ФЕМИДЫ`, Часть 9. Разбор уже сделан, регрессии нет:
тест проверяет не тот файл. Строка 79:

```js
const wf = fs.readFileSync(files[0], 'utf8')
ok(/const ARCHIVE = INBOX \+ '\/_archive'/.test(wf), 'ARCHIVE = INBOX + /_archive ...')
```

`files[0]` — это `$HOME/.claude/workflows/mnemazina-pipeline.js`, а он давно стал шимом из одной
строки `export * from '$MNEMAZINE_HOME/workflows/mnemazina-pipeline.js'`.
Проверяемая строка живёт в каноне, `$MNEMAZINE_HOME/workflows/mnemazina-pipeline.js`,
строка 30, и она на месте.

Правка: брать для этой проверки не `files[0]`, а первый файл из списка, который реально содержит
тело конвейера — то есть пропускать ре-экспорты (файл короче 200 байт со строкой `export * from`).
Одна строка кода, больше ничего.

Это тот же класс дефекта, который сжёг прогон Фемиды: прибор проверяет не тот артефакт и молчит
об этом. Поэтому заодно проследи, чтобы сообщение проверки называло, КАКОЙ файл был прочитан.

Закоммить в репозитории Мнемозины одним коммитом `fix: тест берёт файл с телом конвейера, не шим`.

## Промт проверяющего

ВЕРДИКТ первой строкой: зелёный или красный. Отчёт исполнителя не читай, смотри диск.

1. `node $MNEMAZINE_HOME/tests/test-coverage-fix.mjs` — в выводе `11 passed`,
   ни одного failed.
2. Число проверок не уменьшилось: `grep -c "ok(" ` по файлу теста — не меньше одиннадцати.
   Зелёный тест, полученный удалением проверки, — красный.
3. Проверка ARCHIVE действительно читает файл с телом конвейера, а не шим: в коде есть отсев
   ре-экспортов, и сообщение проверки называет прочитанный путь.
4. `$MNEMAZINE_HOME/workflows/mnemazina-pipeline.js` не изменён:
   `git -C $MNEMAZINE_HOME status --porcelain` не показывает его в правках.
   Правка каталога `scripts/` Мнемозины — красный без разговоров.

Красный, если: тест не даёт 11 passed, число проверок уменьшилось, тронут конвейер или scripts/
Мнемозины, отсев шима сделан жёстким путём вместо признака ре-экспорта.
