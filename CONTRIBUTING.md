# Вклад в Themis

Улучшениям рады. Правила короткие.

- **Никаких данных доверителей.** Из `cases/` не коммитится ничего, кроме
  синтетического примера `cases/ivanov-ivan`. PR с настоящими фамилиями или
  реквизитами закрывается без обсуждения. Это не строгость, это адвокатская тайна.
- **Логика живет в системных путях:** `.claude/`, `scripts/`, `cockpit/`. Данные
  пользователя (`cases/`, `knowledge/`) править не нужно.
- **Local-first.** Распознавание остается на машине: Apple Vision, markitdown,
  whisper. Облачный OCR и Ollama на основном проходе не добавляем.
- **Стиль.** Python по PEP8. Даты в виде `ДД.ММ.ГГГГ`. В документах не пишем
  букву «е» с двумя точками.
- **Перед PR** прогони `bash install.sh` на чистом клоне. Должно встать под ключ,
  без ручной доводки.

Идеи и баги несите в Issues.
