# Форматирование .docx — эталон, выбор метода, проверка

> Параметры всех типов параграфов ЗАШИТЫ в `scripts/create_docx.py` (класс `DocBuilder`) — вручную не задавать, сигнатуры смотреть в классе. Здесь — чего в коде нет: эталон для проверки, выбор метода, микротипография, чек-лист.

## §1 Эталонные параметры (машинная проверка; по ним же — redline-сверка)

Страница А4. Поля: верх 20 / низ 30 (зона штампа экспедиции — Приказ СД РФ № 36) / лево 30 / право 15 мм. L3 и кассация ВС — лево 35 мм: `b.doc.sections[0].left_margin = Mm(35)` после создания DocBuilder (в коде НЕ зашито). Шрифт везде Times New Roman; межстрочный 1.15; абзацный отступ тела 1.25 см; язык ru-RU. Размеры: 14pt — заголовок документа; 13pt — подзаголовок и дата шапки; 12pt — весь остальной текст; 11pt — блок-цитата. Курсив и подчеркивание не используются; цвет авто. Шапка — плавающая таблица справа (колонки 62.4 / 102.3 мм), метки (ИСТЕЦ:) — RIGHT bold, суд и имена — bold; тело JUSTIFY; подпись RIGHT.

Точные sb/sa и отступы каждого типа параграфа — в docstrings методов DocBuilder, сюда не дублируются. Тело не жирное; жирные runs — нормы, суммы, даты, термины (мера — CONTENT §2).

## §2 Выбор метода DocBuilder

| Ситуация | Метод |
|---|---|
| Шапка: суд + стороны + дело | `add_header_table` |
| Досудебный документ (КОМУ/ОТ) | `add_addressee_table` |
| Заголовок / подзаголовок / дата шапки | `add_title` / `add_subtitle` / `add_header_date` |
| Разделы, подразделы | `add_section` / `add_subsection` |
| Абзац тела; жирные фрагменты — список кортежей `(text, bold)` | `add_body`; после маркированного списка — `add_body_spaced` |
| Перечисление | `add_bullet` |
| Дословная норма / цитата 40+ слов | `add_quote` |
| Просительная часть | `add_proshyu` + `add_request_item` (номер «1. » вручную) |
| Приложения | `add_appendices` + `add_appendix_item` |
| Подпись | `add_signature_table(role, name, date)` — предпочтительно (ГОСТ, устойчиво к LibreOffice/GDocs); `add_signature` — legacy |
| Разделители; сохранение | `add_empty`, последним — `add_final_empty`; `save(path)` — авто: стрип «ё», baseline, guard правок |

Нумерации страниц в DocBuilder НЕТ (`add_page_numbers` отсутствует — не вызывать, AttributeError). Документ 2+ страниц по ГОСТ Р 7.0.97 нумеруется: арабские цифры, центр верхнего поля, первая — без номера; колонтитул вручную через XML секции либо согласовать доработку скрипта. Нижний колонтитул — LEFT; правый нижний угол всех страниц свободен (штампы суда).

## §3 Микротипография

| Элемент | Правильно | Ошибка |
|---|---|---|
| Дефис `-` | внутри слова: «во-первых», без пробелов | вместо тире |
| Тире `—` (U+2014) | пунктуация, пробелы с обеих сторон: «Ответчик — ООО» | дефис |
| Среднее тире `–` (U+2013) | диапазоны, без пробелов: «30–90 дней» | «30-90» |
| Кавычки | «елочки»; вложенные — „лапки“: «ООО „Ромашка“» | прямые "..." |
| Многоточие | `…` (U+2026); купюра в цитате — `[...]` | `...` |

Неразрывный пробел (U+00A0) обязателен: `И. И. Иванов` · `г. Москва` · `№ 12` · `2024 г.` · `500 000 рублей` (и между разрядами чисел) · `т. е.` · `§ 156`.
Числа: разряды пробелом (`1 298 300`), десятичный разделитель — запятая. Даты: в тексте `15 марта 2024 года`, в реквизитах `15.03.2024` (ДД.ММ.ГГГГ, не ISO); формат единый по документу.
