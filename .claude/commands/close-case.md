# /close-case — закрыть дело

Вход: папки дела нет → СТОП, показать похожие из `_index.md`. Не указано → из контекста или СПРОСИТЬ. В `_index.md` уже «Закрыто» → сообщить, не менять. Итог неизвестен → СПРОСИТЬ (выиграно/проиграно/мировое/отозвано, решение суда, исполнено ли) — не выдумывать.

## Алгоритм

1. `_case.md`: Стадия → «Закрыто», дата `ДД.ММ.ГГГГ`, раздел «Итог дела» (реквизиты не подтверждены → `требует проверки`). Файла нет → создать минимальный, отметить аномалию.
2. `03_drafts/` (включая `_baselines/`) → `04_archive/`. `00_intake/` и `02_hearings/` НЕ трогать — поданное остается. `mv` упал → перечислить, не терять, спросить.
3. `cases/_index.md`: статус → «Закрыто».
4. `_client.md`: строку из «Активные Дела» → «Закрытые Дела» с результатом; строки не было → добавить в закрытые, рассинхрон отметить.

Материалы остаются в `cases/`. Итог: `✓ Дело закрыто: {клиент}/{дело} · архивировано N · индекс и профиль обновлены`.

## Самопроверка по диску

`_index.md` — «Закрыто» · `_client.md` — дело в закрытых, из активных убрано · `03_drafts/` пуст, `04_archive/` наполнен · `00_intake/` и `02_hearings/` не тронуты · даты `ДД.ММ.ГГГГ`, без «е с точками».
