# /close-case — закрыть дело

## Вход и валидация

| Ситуация | Действие |
|---|---|
| Оба аргумента | Проверить `cases/{клиент}/{дело}/` существует; нет → СТОП, показать похожие строки из `_index.md` |
| Не указано | Дело из контекста сессии; нет → СПРОСИТЬ |
| В `_index.md` уже «Закрыто» | Сообщить и ничего не менять (повторный запуск безопасен) |
| Итог дела неизвестен | СПРОСИТЬ результат (выиграно / проиграно / мировое / отозвано, решение суда, исполнено ли) — не выдумывать |

## Алгоритм

1. `_case.md`: Стадия → «Закрыто», дата закрытия `ДД.ММ.ГГГГ`, раздел «Итог дела»: результат, решение суда с реквизитами (не подтверждены → `требует проверки`), исполнено/нет.
2. Черновики: содержимое `03_drafts/` (включая `_baselines/`) → `04_archive/`. `00_intake/` и `02_hearings/` НЕ трогать — поданное остается на месте.
3. `cases/_index.md`: статус строки дела → «Закрыто».
4. `cases/{клиент}/_client.md`: строку дела из «Активные Дела» → в «Закрытые Дела» с результатом.
5. Итог:

```text
✓ Дело закрыто: {клиент} / {дело}
  Черновики архивированы: {N} файлов
  Индекс и профиль клиента обновлены
  Материалы сохранены в cases/{клиент}/{дело}/
```

Закрытое дело не удаляется — все материалы остаются в `cases/`. Поиск по закрытым — `_index.md`, колонка «Статус».

## Сбои: ситуация → действие

| Ситуация | Действие |
|---|---|
| В `_client.md` нет строки дела | Добавить сразу в «Закрытые Дела», рассинхрон отметить в итоге |
| `mv` в `04_archive/` упал (файл занят) | Перечислить неперенесенные, не терять, спросить пользователя |
| `_case.md` отсутствует | Создать минимальный с разделом «Итог дела», отметить аномалию |

## Самопроверка перед возвратом (по диску)

- [ ] Перечитать `_index.md` — статус «Закрыто»
- [ ] Перечитать `_client.md` — дело в «Закрытые Дела», из «Активных» убрано
- [ ] `ls 03_drafts/` пуст (или остаток объяснен), `04_archive/` содержит файлы
- [ ] `00_intake/` и `02_hearings/` не тронуты
- [ ] Даты `ДД.ММ.ГГГГ`, нет буквы «ё»
