# /draft — процессуальный документ (шаг 4 workflow)

Обертка: маркеры → скилл `doc-drafter`; судебные документы — ТОЛЬКО через него. Дело/тип — из аргументов или контекста (объявить); не определяются → СПРОСИТЬ, не угадывать (тип: иск/возражения/жалоба/ходатайство/заявление).

## Маркеры в `01_context/` — grep по диску ДО запуска; нет → СТОП, drafter не стартовать

| Файл | Маркер | Нет → СТОП: |
|---|---|---|
| `knowledge-map.md` | `## КАРТА ГОТОВА ✓` | «шаг 1: case-mapper» |
| `practice.md` | `grep "СОВЕТ ЗАВЕРШ"` (в старых файлах старое написание) | «шаг 2: охота → /askacouncil; FAST — синтез» |
| `positions.md` (L2/L3) | `СОГЛАСОВАНО СОВЕТОМ` | «шаг 3: /position-council» |

`positions.md` не требуется при L1/FAST либо пропуске, зафиксированном в `_case.md`.

## Запуск и цикл

`doc-drafter` → `03_drafts/{док}_v1.md` + `.docx` (`create_docx.py`); перед составлением читает `knowledge/redlines.md`; правовое утверждение без источника не включать; сужение требований — только письменным решением в `positions.md`. Затем `doc-reviewer` (Кони).

Цикл ≤2 раундов: `ГОТОВ К ПОДАЧЕ` → конец · ТРЕБУЕТ ПРАВОК → `_v2.md` → снова Кони · КРИТИЧЕСКИЕ ОШИБКИ или 2 раунда без одобрения → СТОП, вынести пользователю.

- Замечание раунда 2 повторяет раунд 1 → СТОП, не крутить: доложить замечание и причину незакрытия.
- Лог: строка на раунд в `03_drafts/_working/review_log.md`: `[ДД.ММ.ГГГГ] {док} r{N}: вердикт; закрыто; осталось`.
- Кони критикует цифры (пошлина, сроки) → сверить по первоисточнику ДО правки.
- drafter упал / неполный → перезапуск ≤2, затем СТОП с причиной.

## Самопроверка

Маркеры grep-ом, не по памяти · `.md` и `.docx` на диске · вердикт Кони — пользователю дословно · даты `ДД.ММ.ГГГГ`, без «е с точками».
