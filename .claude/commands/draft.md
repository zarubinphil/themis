# /draft — процессуальный документ (шаг 4 workflow)

Тонкая обертка: проверить входные маркеры → запустить скилл `doc-drafter`. Судебные документы делаются ТОЛЬКО через него.

## Вход и валидация

`$ARGUMENTS` = `{тип документа} для {клиент}/{дело}` (пример: `/draft возражения для doveritel/razdel-imushchestva-2026`).

| Ситуация | Действие |
|---|---|
| Тип и дело указаны | → проверка маркеров |
| Дело не указано, одно обсуждается в сессии | Подставить его, объявить |
| Дело не определяется | СПРОСИТЬ, не угадывать |
| Тип документа не указан | СПРОСИТЬ (иск / возражения / жалоба / ходатайство / заявление) |

## Проверка входных маркеров — ДО запуска drafter (grep по диску)

Файлы в `cases/{клиент}/{дело}/01_context/`:

| Файл | Обязательный маркер | Нет маркера → СТОП с текстом |
|---|---|---|
| `knowledge-map.md` | `## КАРТА ГОТОВА ✓` | «Запусти case-mapper (шаг 1)» |
| `practice.md` | `## СОВЕТ ЗАВЕРШЕН` | «Запусти охотников → /askacouncil (шаг 2); FAST — синтез practice.md» |
| `positions.md` (только L2/L3) | `СОГЛАСОВАНО СОВЕТОМ` | «Запусти /position-council (шаг 3)» |

`positions.md` не требуется, если: уровень L1/FAST, либо в `_case.md` зафиксирован пропуск («юрист знает позицию»). Проверка маркера practice: `grep -E "СОВЕТ ЗАВЕРШ(Е|Ё)Н"` — в старых файлах вариант с «ё»; новые пишутся без «ё».

## Запуск

Активировать скилл `doc-drafter` (Сперанский). Ключевые правила исполнения:

1. Черновик → `03_drafts/{документ}_v1.md`, на основе knowledge-map / practice / positions; перед составлением читать `knowledge/redlines.md`.
2. Каждое правовое утверждение — с источником в тексте: `[ст. 333 ГК РФ]`, `[Пленум ВС РФ от ДД.ММ.ГГГГ № X, п. Y]`, `[дело № А65-XXXXX/2024]`. Без источника — не включать.
3. Сужение требований/ходатайств против `positions.md` — только письменным решением в `positions.md`, иначе Кони вернет документ.
4. После черновика — `doc-reviewer` (Кони), 7 блоков проверки.

Цикл (до 2 раундов): `ГОТОВ К ПОДАЧЕ` → `.docx` через `scripts/create_docx.py` → конец. ТРЕБУЕТ ПРАВОК → `_v2.md` → снова Кони. КРИТИЧЕСКИЕ ОШИБКИ либо 2 раунда без одобрения → СТОП, вынести пользователю.

## Сбои: ситуация → действие

| Ситуация | Действие |
|---|---|
| Маркер отсутствует | СТОП + что запустить (таблица выше), drafter не стартовать |
| doc-drafter упал / неполный результат | Перезапуск до 2 раз, затем СТОП с причиной |
| Кони критикует цифры (пошлина, сроки) | Замечание сверить по первоисточнику ДО правки — бывают ложные тревоги (пошлина физлица vs организации) |

## Самопроверка перед возвратом

- [ ] Маркеры проверены grep по диску, не по памяти
- [ ] `.md` и `.docx` существуют на диске
- [ ] Вердикт Кони получен и передан пользователю дословно
