# /finalize — финальный PDF с подписью

Вход: путь к `.docx`, либо `{клиент}/{дело}` → готовый Word по `python3 scripts/case_paths.py --document-contract cases/{клиент}/{дело}` или документ последнего события (объявить какой), либо дело из контекста; нет → СПРОСИТЬ. Вердикта `ГОТОВ К ПОДАЧЕ` нет → предупредить, продолжать только по явному подтверждению.

## 1. Guard правок доверителя — ДО любых операций (прецедент: правки в Word затерты пересборкой)

1. Снимок `.agent/drafts/_baselines/{имя}.docx` есть → извлечь оба (`markdown_extract.py --json-meta`), сравнить; авторство: `officecli get FILE /` → `lastModifiedBy`/`revisionNumber` (фолбэк `unzip -p FILE docProps/core.xml`), рецензирование → `/revision`.
2. Отличия → правки доверителя → СТОП: не пересобирать, не перезаписывать; предложить redline-разбор («изучи мои правки») или спросить.
3. Снимка нет → предупредить, продолжать по подтверждению. Отличий нет → далее.

## 2. Подпись и PDF

1. Нет `cases/_assets/подпись.png` → сообщить, предложить `--no-sign`.
2. `scripts/sign_and_pdf.py "{docx}"` (`--no-sign` — только PDF, `--sign-only` — подпись на готовый PDF); конвертация через Word; сбой → повтор 1 раз, снова → СТОП (PDF вручную).

## 3. Пакет и статус

`.md` + `.docx` + `.pdf` → `02_hearings/{ДД-ММ-ГГГГ}_{событие}/` (папки нет → создать через /new-event, дату СПРОСИТЬ; в корень `02_hearings/` не класть) → отметка в `_event.md`: подписан/подан, дата `ДД.ММ.ГГГГ` → документ ПОДАН, не редактировать; правки — новым документом.

## Самопроверка по диску
