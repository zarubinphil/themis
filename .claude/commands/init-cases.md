# /init-cases — прогрев карт знаний

## Алгоритм

1. Прочитать `cases/_index.md` → все дела со статусом «Активно». Файла нет → СТОП, сообщить.
2. Для каждого дела проверить `01_context/knowledge-map.md` (grep по диску):

| Состояние | Группа |
|---|---|
| Файла нет, в `00_intake/` есть материалы | Прогрев |
| Файл есть + маркер `## КАРТА ГОТОВА ✓` | Готово — НЕ трогать, НЕ перезаписывать |
| Файл есть, маркера нет | Незавершен — предложить перезапуск case-mapper отдельно, с подтверждением |
| `00_intake/` пуст | Пропустить с пометкой |

3. Показать группы, спросить подтверждение:

```text
Найдено активных дел: N
  Нужен прогрев (N): клиент/дело, ...
  Уже готово (N): ...  Незавершено (N): ...  Пусто (N): ...
Запустить case-mapper для дел без карты? [да/нет]
```

4. Запустить `case-mapper` для группы «Прогрев» параллельно, НЕ более 3 одновременно. Каждому — путь `cases/{клиент}/{дело}/`.
5. Результат каждого проверить по диску: файл создан + маркер `## КАРТА ГОТОВА ✓` есть. Нет → перезапуск (до 2 раз), после — в «Ошибки». Карту за агента НЕ дописывать.

## Отчет

```text
=== Результат /init-cases ===
✓ Готово: клиент/дело — knowledge-map.md создан, N файлов обработано
↷ Пропущено (карта актуальна): ...
⚠ Пропущено (00_intake пуст): ...
✗ Ошибки: клиент/дело — причина
Следующий шаг: /init-practice
```

## Сбои: ситуация → действие

| Ситуация | Действие |
|---|---|
| `Agent type case-mapper not found` | СТОП: реестр агентов загружен старым — полный перезапуск Claude Code (выход, не resume) |
| case-mapper упал / вернул файл без маркера | До 2 перезапусков → «Ошибки»; карту самому не писать |
| `_index.md` отсутствует | СТОП, сообщить пользователю |

## Самопроверка перед возвратом (по диску)

- [ ] Каждое «✓ Готово» подтверждено grep маркера в файле
- [ ] Готовые карты не перезаписаны
- [ ] В отчете учтено каждое активное дело — ни одно не потеряно
