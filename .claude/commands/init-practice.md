# /init-practice — охота за практикой

## Алгоритм

### 0. Сервисы поиска и база знаний

- `sgai validate --json 2>/dev/null` → доступен / недоступен. Объявить статус.
- Приоритет охотников: 1) Firecrawl MCP → 2) ScrapeGraphAI → 3) WebSearch/WebFetch (резерв).
- ДО внешнего поиска — `knowledge/practice_index.md` (grep по категории дела): найдено → использовать, внешний поиск вторичен.

### 1. Отбор дел

Прочитать `cases/_index.md` → активные дела. Для каждого:

| Состояние | Действие |
|---|---|
| Нет `knowledge-map.md` или нет маркера `## КАРТА ГОТОВА ✓` | Пропустить → сначала case-mapper (/init-cases) |
| `practice.md` с маркером, моложе 30 дней | Пропустить (актуально) — НЕ перезаписывать |
| `practice.md` старше 30 дней или без маркера | Обновить |
| `practice.md` нет | Охота |

Маркер practice проверять `grep -E "СОВЕТ ЗАВЕРШ(Е|Ё)Н"` — в старых файлах вариант с «ё»; новые пишутся `## СОВЕТ ЗАВЕРШЕН`, без «ё». Показать группы, спросить подтверждение перед запуском.

### 2. Состав охотников на дело

Читать блок `## ОХОТНИКИ — РЕШЕНИЕ ФЕМИДЫ` в knowledge-map.md. Блока нет → по числу правовых вопросов (раздел 7 карты):

| Вопросов | Уровень | Состав |
|---|---|---|
| 1 | L1 | tactical |
| 2-3 | L2 | classic + tactical; + skeptic, если оппонент — организация |
| 4+ / кассация ВС / КАС | L3 | все три |

### 3. Запуск

Дела обрабатывать по очереди; охотников одного дела — параллельно через Agent tool: `practice-hunter-classic`, `practice-hunter-skeptic`, `practice-hunter-tactical` (по составу). Каждому передать путь `cases/{клиент}/{дело}/`.

### 4. Синтез и архивация

- L2/L3 (FULL) → `/askacouncil {путь}` → `practice.md` с маркером.
- L1/FAST → тактик пишет `practice.md` напрямую с маркером.
- После завершения → `archivist` с путем к делу (пополнение `knowledge/practice_index.md`).

### 5. Отчет

```text
=== Результат /init-practice ===
✓ Готово: клиент/дело — practice.md, маркер проставлен
⚠ Частично: клиент/дело — охотники завершены, нужен /askacouncil
↷ Пропущено (актуально / нет карты): ...
✗ Ошибки: клиент/дело — причина
Следующий шаг: L2/L3 → /position-council → positions.md → /draft
```

## Сбои: ситуация → действие

| Ситуация | Действие |
|---|---|
| hunter_*.md содержит <3 источников с реквизитами дел | Не принимать, перезапуск охотника (до 2 раз), затем «Частично» |
| Все сервисы поиска недоступны | СТОП по делу: практика из памяти — только с пометкой `требует верификации`, доложить |
| `Agent type ... not found` | СТОП: реестр агентов старый — полный перезапуск Claude Code |
| /askacouncil не проставил маркер | Перезапуск (до 2 раз), затем «Частично» с причиной |
