# Уроки по правкам доверителя (redline self-learning)

> Самообучающаяся база. Сюда Фемида заносит уроки из правок, которые доверитель
> внёс в готовые документы. Цель — не повторять одни и те же огрехи.

## Как это работает

1. Фемида выдаёт документ (`.agent/drafts/<имя>.md` — её черновик, `<имя>.docx` — для подачи).
2. Доверитель открывает `.docx`, правит под себя, сохраняет.
3. Доверитель жмёт на карточке документа **«Изучить правки»** (или пишет в чат
   «изучи мои правки по <дело>»).

---

Живой журнал — `knowledge/redlines.md` рядом с этим файлом. В git он не входит:
каждая строка несёт «дата · дело», то есть фамилию доверителя, а репозиторий
публичный (прецедент 04.08.2026 — опубликованный коммит остаётся в форках и
зеркалах после удаления). Этот файл — только формат записи.

Формат строки:

    - [ДД.ММ.ГГГГ · клиент/дело-год] правило, которое доверитель установил правкой

Правило пишется так, чтобы его можно было исполнить в следующем документе, не
открывая дело: что именно менять, а не что было изменено однажды.
