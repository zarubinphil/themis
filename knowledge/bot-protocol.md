# Бот Фемиды — порядок для владельца

> Всё, что уходит в Telegram, разглашено Telegram. Бот поэтому — пульт: команда,
> статус, дата. Ни ФИО, ни номера дела, ни суммы наружу не уходит; документ
> забирается по ссылке внутрь приватной сети, где владельца узнаёт панель.
> Токен панели в ссылку не кладётся: отправить его в чат значит разгласить.
>
> Бот персональный. Общего бота нет никогда: каждый заводит своего в BotFather.
> Пустой конфиг = бота нет, система работает без него целиком.

## Что делает владелец (наружу, автономно не делается)

1. **Завести бота.** BotFather → `/newbot` → имя → выдаст токен.
2. **Положить секрет.** Создать своим редактором файл `~/.secrets/themis-telegram.env`
   с правами `600` и двумя строками:

   ```
   THEMIS_TELEGRAM_BOT_TOKEN=токен, который выдал BotFather
   THEMIS_TELEGRAM_CHAT_ID=номер вашего чата (см. шаг 3)
   ```

   В репозиторий значение не попадает никогда — ни в код, ни в примеры, ни в логи:
   репозиторий публичный, и приёмка отдельно проверяет, что формы токена в
   отслеживаемых файлах нет вовсе.
3. **Узнать свой chat_id.** Написать боту любое сообщение, затем подгрузить
   переменные из файла в окружение (`set -a` + точка + `set +a`) и выполнить:

   ```
   python3 scripts/themis_bot.py --chat-probe
   ```

   Прибор печатает номера чатов, которые боту писали. Свой дописать в тот же файл.
4. **Включить бота в конфиге** `~/.themis/config.json`:

   ```json
   { "bot": { "enabled": true } }
   ```

   Секрета в конфиге быть не должно — только имя переменной; `themis_config --check`
   такой конфиг отвергает.
5. **Аватар.** `python3 scripts/bot_avatar.py --out ~/.themis/femida-avatar.png`,
   затем BotFather → `/setuserpic`. Bot API менять фото профиля не умеет — только руками.
6. **Проверить и запустить:**

   ```
   python3 scripts/themis_bot.py --check     # готовность; значение секрета не печатает
   python3 scripts/themis_bot.py --serve     # опрос на весь день
   ```

## Как это живёт дальше

- **Опрос, а не webhook.** Инициатива всегда наша, входящий порт сервер не открывает.
- **Один опрашивающий на машину.** Второй экземпляр откажется стартовать: два процесса
  делят обновления между собой, и половина сообщений осталась бы без ответа.
- **Напоминание о заседаниях** уходит из `scripts/morning-briefing.sh` (launchd, 9:00):
  только даты и счёт. Заседаний нет — бот молчит, а не пишет «сегодня ничего»:
  ежедневный шум перестают читать вместе с настоящим.
- **Голосовые** расшифровываются на этой машине (SMLTLK на Маке, whisper на сервере).
  Движка нет — отказ, а не облако. Расшифровка в чат не возвращается: сказанное
  вслух остаётся здесь, задача уходит в очередь `~/.themis/voice-queue.jsonl`.
- **Мини-приложение** — `/miniapp` на панели: дела, ближайшие события, кнопка «собрать
  документ». Живёт внутри приватной сети и закрыто тем же токеном, что и `/api/`.
  С телефона открывается, когда телефон в этой сети.

## Если токен утёк

Порядок тот же, что и у панели (`knowledge/server-protocol.md`, раздел про секрет):
BotFather → `/revoke` (старый токен умирает немедленно) → новый в файле секретов →
перезапуск. Переписка, уже ушедшая в Telegram, отзыву не подлежит — на этом и
построен запрет называть в чате имена и номера.

## Чего бот не делает

- Не пересылает файлы: только ссылку внутрь сети.
- Не отвечает никому, кроме одного chat_id; чужое сообщение уходит в аудит без текста.
- Не эхо-ит присланное: написанное владельцем в чат обратно в чат не возвращается.
- Не режет длинные уведомления на куски: не влезло в одно сообщение — событие
  описано слишком подробно, подробности живут в панели.
