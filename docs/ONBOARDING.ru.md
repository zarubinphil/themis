# Онбординг

Этот путь написан так, будто вы юрист, а не инженер, и никогда ничего не ставили из терминала. На каждом шаге сказано, что сделать и что вы должны увидеть.

Короткий путь — разговорный: откройте проект в Claude Code и запустите `/themis-setup`. Фемида представится, спросит о вашей практике по одному вопросу, объяснит, зачем каждый из них, и ничего не поставит без вашего «да». Ниже — та же дорога пешком.

Нужны Mac для локального распознавания сканов, Python 3.11 или новее, Xcode Command Line Tools и Claude Code.

1. **Заберите проект.**

   ```bash
   git clone https://github.com/zarubinvibe/themis.git
   cd themis
   ```

   Вы увидите папку `themis`, приглашение терминала окажется внутри неё.

2. **Откройте в ней Claude Code.**

   ```bash
   claude
   ```

   Вы увидите, что агент запустился внутри проекта.

3. **Запустите ведомую установку.** Введите `/themis-setup`.

   Вы увидите, как Фемида представляется, а затем спрашивает о практике: какие дела ведёте чаще, регион, суды, куда складываете входящие, есть ли электронная подпись, нужны ли напоминания в Telegram. По одному вопросу, к каждому — зачем спрашивает и как ответить.

4. **Дайте ей проверить компьютер до установки.**

   Она назовёт, чего не хватает, сколько это весит, зачем ей это и что без этого не заработает. Ничего не ставится, пока вы не скажете вслух. Молчание считается отказом.

5. **Услышьте честные ограничения.** Локальное распознавание сканов работает на Apple Vision и есть только на macOS. На Windows и Linux останутся текстовые PDF, DOCX и XLSX, и всё. Вы узнаёте это сейчас, а не в тот четверг, когда принесёте папку сканов.

6. **Посмотрите, как приезжают законы.** Сначала кодексы под вашу практику, остальное добирается фоном, дальше редакции сверяются раз в месяц.

   Вы увидите корпус у себя на диске. Нормы цитируются из него, а не пересказываются по памяти.

7. **Передайте одну настоящую папку дела.** Не демонстрационную: свою.

   Вы увидите, как сканы распознаются локально, примерно полторы секунды на страницу, а ИНН, ОГРН, номера дел и суммы проверяются контрольной суммой.

8. **Прочитайте карту дела.** Стороны, даты, требования и доказательства в одном месте.

   Вы увидите один файл вместо двухсот страниц, которые надо перечитывать.

9. **Попросите практику за вас и против вас.** Один агент ищет поддержку, другой процессуальные ходы, третий намеренно ищет то, чем воспользуется оппонент.

   Вы увидите обе стороны спора до того, как их приведёт другая сторона.

10. **Возьмите проект документа на правку.** Один агент пишет, другой, который его не писал, проверяет. Собрать документ раньше проверки нельзя, формат сверяется перед подачей, сторож персональных данных проходит по каждому коммиту.

    Вы увидите проект, который правите как юрист, а не текст, который надо перепроверять построчно. Мышление и решения остаются вашими.

## Как обновляться дальше

Когда выйдет новая версия, не клонируйте заново: откройте проект в Claude Code и запустите `/themis-update`. Он сначала покажет, что изменится, потянет изменения только вперёд, не тронет папки дел и после обновления прогонит проверки.

## Если это помогло

Если Фемида сняла с вашего стола механику, поставьте звезду: [https://github.com/zarubinvibe/themis](https://github.com/zarubinvibe/themis). Это секунда, а от неё зависит, найдут ли её другие юристы.

Вы прогнали её на настоящем деле, значит, вы и есть тот, кто может её улучшить. Дорога короткая: сделайте fork, заведите ветку, оформите commit, отправьте push и откройте Pull Request. Прямой push в `main` релизный gate отклонит.

Шаг соврал? Заведите issue на [https://github.com/zarubinvibe/themis/issues](https://github.com/zarubinvibe/themis/issues) и опишите на выдуманных данных. Настоящие материалы доверителя в публичный issue не прикладывают никогда.
