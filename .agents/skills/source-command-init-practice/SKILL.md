# source-command-init-practice

Use this skill when the user asks to run the migrated source command `init-practice`.

## Command Template

# /init-practice — охота за практикой

0. `sgai validate --json` → объявить статус. Приоритет: Firecrawl → ScrapeGraphAI → WebSearch. ДО внешнего поиска — grep `knowledge/practice_index.md` по категории: найдено → использовать.
1. `cases/_index.md` → активные дела. Отбор grep-ом по диску, не Read:

| Состояние | Действие |
|---|---|
| Нет карты или маркера `## КАРТА ГОТОВА ✓` | Пропустить → сначала /init-cases |
| `practice.md`: `grep "СОВЕТ ЗАВЕРШ"` есть, моложе 365 дней (PRACTICE_TTL_DAYS) | Пропустить, НЕ перезаписывать |
| Маркера нет / старше 365 дней / файла нет | Охота |

Показать группы, спросить подтверждение.

2. Состав — блок `## ОХОТНИКИ — РЕШЕНИЕ ФЕМИДЫ` карты; нет → по числу правовых вопросов: 1 = L1 tactical · 2-3 = L2 classic + tactical (+ skeptic при орг-оппоненте) · 4+ / кассация ВС / КАС = L3 все три.
3. Запуск: дела по очереди, охотники дела параллельно (`practice-hunter-classic`/`-skeptic`/`-tactical`). В промпт — правовые вопросы карты ТЕКСТОМ (материал до 15 000 токенов — текстом, не путем) + путь дела.
4. Синтез: FULL → `/askacouncil {путь}` → `practice.md` с маркером; L1/FAST → Фемида синтезирует `practice.md` сама (Opus) и ставит маркер `## FAST-СИНТЕЗ ФЕМИДЫ`; охотник кладёт только `tactical_*.md`. Затем `archivist` (один раз).
5. Отчет: `✓ Готово` (маркер) / `⚠ Частично` (нужен /askacouncil) / `↷ Пропущено` / `✗ Ошибки` + причина. Далее: /position-council → /draft.

## Сбои

`hunter_*.md` <3 источников с реквизитами → перезапуск ≤2, затем «Частично» · сервисы недоступны → СТОП по делу, из памяти только с пометкой `требует верификации` · `Agent type not found` → СТОП, полный перезапуск Codex · маркер не проставлен → перезапуск ≤2.

## Самопроверка по диску

Каждое «✓» подтверждено grep маркера · актуальные `practice.md` не тронуты · `archivist` запущен · каждое активное дело в отчете · даты `ДД.ММ.ГГГГ`, без «е с точками».
