# Установка Фемиды с нуля

`themis-update` обновляет уже установленную систему. Этот скилл ставит её впервые — на чужой машине, чужой платформе, у юриста с другой практикой.

**Главное правило: не угадывать.** Ни про практику владельца (спросить), ни про окружение (проверить командой). Молчаливая деградация запрещена: если движок OCR недоступен, это называется вслух, а не остаётся сюрпризом на первом деле со сканами.

## 1. Спросить, а не додумать

Задать владельцу семь вопросов и записать ответы. Спрашивать по одному, не списком: на список отвечают первым пунктом и «остальное потом».

| # | Вопрос | Что определяет |
|---|---|---|
| 1 | Чем занимаетесь: какие категории дел ведёте чаще всего? | какие кодексы тянуть в корпус первыми, какие категории в `practice_index.md` |
| 2 | Суды общей юрисдикции, мировые судьи, арбитраж — что из этого ваше? | разделы `practice_search.py`, нужен ли арбитражный контур |
| 3 | Регион и основные суды? | `--area` по умолчанию, канон названий через `--find-court` |
| 4 | Дела уже есть в бумаге или начинаем с чистого листа? | нужен ли разовый прогрев `/init-cases` |
| 5 | Куда кладёте входящие материалы? | путь инбокса (по умолчанию `~/Desktop/inbox`) |
| 6 | Кто ещё видит эти файлы: только вы, помощник, бухгалтерия? | режим доступа, нужна ли чистка кеша при закрытии дела |
| 7 | Готовы ли документы подписывать электронно? | нужен ли контур `sign_and_pdf.py` |

Ответы записать в `cases/_logs/setup_ДД-ММ-ГГГГ.md`. Это не анкета для галочки: из ответа 1 напрямую следует, какие кодексы выгружать, а выгрузка всего корпуса занимает полчаса.

## 2. Проверить окружение фактом

```bash
python3 scripts/setup_doctor.py            # человеку
python3 scripts/setup_doctor.py --json     # разбирать самому
```

Доктор проверяет КОМАНДАМИ: версию Python, curl, git, импорт markitdown/pymupdf/python-docx, запуск `bin/vision-doc`, наличие четырёх шрифтов стандарта в системе, объём корпуса права, доступность ЦБ РФ, производственного календаря, sudact и publication.pravo.gov.ru, и прогоняет десять `--selftest` самих скриптов.

Коды: `0` всё критичное на месте · `1` есть критичное · `2` только предупреждения.

**Красную строку не пересказывать своими словами и не смягчать.** У каждой есть поле «как починить» с готовой командой — показать её владельцу дословно.

## 3. Платформа

Доктор печатает раздел «Что на этой платформе иначе». Разобрать его вместе с владельцем — молча пропускать нельзя.

| Платформа | OCR сканов | Фоновые задания | Отдельно |
|---|---|---|---|
| **macOS** | `bin/vision-doc` (Apple Vision), локально, $0 | launchd, `scripts/*.plist` | — |
| **Windows** | **НЕТ.** Apple Vision — фреймворк Apple | Планировщик задач (`schtasks /create`) | UTF-8 в консоли (`chcp 65001`), `core.autocrlf=input` |
| **Linux** | **НЕТ** | systemd-таймеры (`systemctl --user enable --now`) | локаль UTF-8, иначе `os.listdir` отдаёт битые имена дел |

Не-macOS: текстовые PDF, DOCX и XLSX читаются через markitdown и работают полностью. **Сканы и фотографии документов не читаются вовсе.** Владельцу это сообщается прямо, до первого дела, а не после пустой карты. Варианта два: вести дела со сканами на macOS либо подключить свой движок — реализовать интерфейс `bin/vision-doc` (вход файл, выход `page_NNN.txt` и `page_NNN.md` с таблицами) и указать путь в `THEMIS_VISION_DOC`.

**Чужую модель OCR не ставить без сравнительного замера на реальных сканах дела.** PaddleOCR, Surya, MinerU и Unlimited-OCR уже отклонены по замеру — последний разрушал кириллицу и выдумывал содержимое (`knowledge/lessons-log.md`).

## 4. Развернуть

```bash
bash install.sh                                        # пакеты, сборка OCR, каталоги
python3 scripts/update_legal_corpus.py --init          # кодексы (по ответу 1)
python3 scripts/update_legal_corpus.py --plenums       # Пленумы ВС РФ, ~10 минут
python3 scripts/setup_doctor.py                        # повторно: стало ли зелёным
```

Корпус тянуть под практику владельца. Семейные дела — СК, ГПК, ГК; арбитраж — АПК, ГК, банкротство; уголовные — УК, УПК. Всё сразу тянуть не обязательно, добрать можно потом тем же скриптом.

## 5. Проверить на живом, а не на синтетике

Взять один настоящий документ владельца и провести его целиком:

```bash
python3 scripts/markdown_extract.py ДОКУМЕНТ --json-meta   # маршрут и кеш
python3 scripts/quality_gate.py --ocr ПАПКА_OCR            # качество распознавания
python3 scripts/cite.py "ст. 131 ГПК"                       # дословная норма с диска
python3 scripts/gosposhlina.py --cena 450000                # расчёт из корпуса
python3 scripts/sroki.py --ot ДД.ММ.ГГГГ --mesyacev 1       # срок с календарём
```

Пустой результат на настоящем документе — установка не завершена, а не «модель не справилась».

## 6. Вернуть доработку в GitHub

Если под платформу пришлось что-то переработать (маршрут OCR, планировщик, пути), это стоит вернуть — следующий на той же платформе не пройдёт тот же путь заново.

**Пуш только с явного согласия владельца. Перед пушем — обязательная проверка на персональные данные:**

```bash
git status --short                    # что вообще меняется
git diff --cached --stat              # объём
git ls-files cases/ | head            # ДОЛЖНО БЫТЬ ПУСТО
grep -rn "cases/" --include='*.py' scripts/ | grep -v "cases_dir\|args.cases\|default=\"cases\"" | head
```

Инвариант без исключений: `cases/` и всё производное от него в публичный репозиторий не попадает. **Имя папки дела — это фамилия человека, оно тоже персональные данные:** пути дел не должны появляться ни в коде, ни в комментариях, ни в примерах, ни в логах, ни в сообщении коммита.

Что возвращать: код платформенной поддержки, исправления, новые проверки. Что не возвращать: настройки конкретной практики, пути инбокса, что угодно из `cases/` и `knowledge/practice_index.md`.

## Сбои

| Ситуация | Действие |
|---|---|
| Доктор красный, владелец торопится | назвать поимённо, что не работает и на каком шаге всплывёт; не начинать дело с красным OCR |
| Не-macOS, а дела со сканами | сказать прямо на этапе установки; предложить обе развилки, решение за владельцем |
| Корпус не тянется (канал недоступен) | `update_legal_corpus.py` вернёт ненулевой код и назовёт канал; без корпуса `cite.py` норм не отдаст — это блокирует шаг 4 протокола |
| Шрифтов нет | документ соберётся, но Word подставит свои — в суд уйдёт не то, что проверялось; поставить до первого документа |
| `--selftest` красный на чистой машине | это дефект установки, а не «так и было»: запустить проваленный вручную, он называет сломанную проверку |
