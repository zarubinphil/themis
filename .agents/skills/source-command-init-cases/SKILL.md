# source-command-init-cases

Use this skill when the user asks to run the migrated source command `init-cases`.

## Command Template

# /init-cases — прогрев карт знаний

1. `cases/_index.md` → дела «Активно»; файла нет → СТОП.
2. Группировка grep-ом по диску, не Read: карты нет + `00_intake/` не пуст → Прогрев · маркер `## КАРТА ГОТОВА ✓` есть → НЕ трогать, НЕ перезаписывать · файл без маркера → перезапуск отдельно, с подтверждением · интейк пуст → пропустить с пометкой.
3. Показать группы (прогрев/готово/незавершено/пусто), спросить подтверждение запуска.
4. **Отметка прогона (иначе сторож заблокирует спавн).** Каждому делу «Прогрев» ДО запуска: `python3 scripts/case_paths.py --run-set cases/{клиент}/{дело} guide init-cases`. Затем `case-mapper` для группы параллельно, ≤3 одновременно; каждому путь `cases/{клиент}/{дело}/`.
5. Результат по диску: файл + маркер; нет → перезапуск ≤2, затем «Ошибки». Карту за агента НЕ дописывать.

Отчет: `✓ Готово` / `↷ Карта актуальна` / `⚠ 00_intake пуст` / `✗ Ошибки` + причина. Далее: /init-practice.

## Сбои

`Agent type case-mapper not found` → СТОП: реестр агентов стар, полный перезапуск Codex (выход, не resume) · `_index.md` отсутствует → СТОП.

## Самопроверка по диску

Каждое «✓» подтверждено grep маркера · готовые карты не перезаписаны · каждое активное дело учтено · даты `ДД.ММ.ГГГГ`, без «е с точками».
