# source-command-new-event

Use this skill when the user asks to run the migrated source command `new-event`.

## Command Template

# /new-event — событие по делу

Название латиницей-дефисами (`osnovnoe-zasedanie`). Дела нет в `cases/` → СТОП, показать похожие из `_index.md`, предложить /new-case. Дело не указано → из контекста или СПРОСИТЬ. Даты нет → СПРОСИТЬ, сегодняшнюю не ставить; иной формат → привести к `ДД-ММ-ГГГГ`, объявить. Папка события уже существует → СТОП, не затирать.

## Алгоритм

1. Создать `cases/{клиент}/{дело}/02_hearings/{ДД-ММ-ГГГГ}_{название}/`.
2. `_event.md` по `cases/_templates/_event.md` (шаблона нет → разделы «ДО СОБЫТИЯ» / «ПОСЛЕ СОБЫТИЯ», отметить). Суд / № дела / судья — из `_case.md`; нет данных → `—`, не выдумывать.
3. `_case.md`: «Следующее заседание» → дата `ДД.ММ.ГГГГ` (если будущее); «Журнал событий» → `| ДД.ММ.ГГГГ | {тип} | — |`. Файла нет → событие создать, аномалию отметить.

Итог: `✓ Событие: {путь}` + «заполни _event.md; документы — /draft, подготовка — hearing-prep».

## Самопроверка по диску

Папка и `_event.md` существуют (`ls`) · `_case.md` перечитан: дата и журнал обновлены · даты в текстах `ДД.ММ.ГГГГ`, в имени папки `ДД-ММ-ГГГГ` · без «е с точками».
