# Требования к процессуальным документам РФ — справочник

> Актуальность 15.04.2026. Пошлины — ФЗ от 08.08.2024 № 259-ФЗ (с 09.09.2024); Пленум ВС РФ от 23.12.2025 № 39. Спорное сверять по актуальной редакции (pravo.gov.ru). С 01.09.2026 планируется новый порядок уплаты пошлины проигравшим ответчиком — отслеживать.

## §1 Исковое заявление (ГПК ст. 131-132 · АПК ст. 125-126 · КАС ст. 125-126)

Общий состав: суд; стороны с реквизитами (ниже); в чем нарушение прав; обстоятельства + доказательства; цена иска и расчет (если оценивается); досудебный порядок; действия по примирению; приложения; дата, подпись (истец или представитель).

Реквизиты сторон: гражданин — ФИО, дата и место рождения, место жительства + ОДИН идентификатор (СНИЛС / ИНН / паспорт / вод. уд. / ОГРНИП); для ответчика — и место работы, если известно. Организация — наименование, адрес, ИНН, ОГРН.

| Кодекс | Особенности |
|---|---|
| ГПК | подача: бумага или ГАС «Правосудие» |
| АПК | претензионный порядок 30 дней (если иное не в законе/договоре); требования со ссылками на НПА; меры обеспечения до иска; выписки ЕГРЮЛ/ЕГРИП не старше 30 дней (или ссылка на ФНС); «Мой арбитр» |
| КАС | «административный истец/ответчик»; НПА, на соответствие которым проверяется акт; сведения о высшем юробразовании (если истец сам ведет дело, где представитель обязателен); заинтересованные лица; по отдельным категориям — спецтребования глав КАС |

УКЭП: электронная подача + ходатайство об обеспечении / предварительной защите → УКЭП обязательна (все кодексы).

Приложения: копии по числу участников + доказательства направления; пошлина (или льгота/отсрочка); доказательства; расчет; досудебка; доверенность. АПК: + свидетельство о регистрации; определение об обеспечении; проект договора (при понуждении).

## §2 Отзыв, возражения, письменные объяснения

| Кодекс | Нормы | Состав |
|---|---|---|
| ГПК — возражения | ст. 35, 149, 150 (формы нет) | суд; № дела, стороны; заявитель, статус; опровержение доводов + нормы + доказательства; просительная часть («отказать полностью / в части»); приложения; дата, подпись |
| АПК — отзыв | ст. 131 | суд; истец, № дела; возражения со ссылками на НПА (+ расчет); при частичном признании — в какой части; приложения. Направить участникам заблаговременно, доказательства приложить |
| КАС | ст. 135, 136 | суд, № дела, стороны; возражения + нормы; доказательства; просительная часть; дата, подпись |

## §3 Ходатайства (ГПК 35, 166 · АПК 41, 159 · КАС 45, 154; формы нет — практика)

Состав: суд; № дела, стороны; наименование с видом; заявитель, статус; обосновывающие обстоятельства; нормы; четкая просьба; приложения; дата, подпись.

Особые виды — дополнительно: обеспечение иска (ГПК 139-141; АПК 90-93; КАС 85-88) — конкретная мера + обоснование, эл. подача → УКЭП; истребование доказательств — что, у кого, что подтверждает; экспертиза — вид, вопросы, кандидатуры; восстановление срока — причины пропуска + доказательства уважительности; отложение — причина + доказательства (больничный, командировка).

## §4 Апелляционная, кассационная, надзорная жалобы

Нормы: апелляция — ГПК 322 / АПК 260 / КАС 299; кассация — ГПК 378 / АПК 277 / КАС 320.
Состав: суд-адресат; заявитель (статус, адрес); участники дела; реквизиты обжалуемого акта (суд, дата, № дела, суть); основания неправильности с нормами; просительная часть (отменить / изменить / на новое рассмотрение); приложения (копия акта, пошлина); дата, подпись.

## §5 Семейные дела (ГПК + СК РФ)

| Вид | Дополнительно в заявлении |
|---|---|
| Расторжение брака (СК 21-23) | дата/место регистрации; дети; согласие второго супруга; причины; объединяемые требования. Несовершеннолетние дети → только суд |
| Алименты (СК 80-120) | ФИО, дата рождения ребенка; доходы ответчика; форма — доля или твердая сумма |
| Отцовство (СК 48-50) | ребенок; актовая запись; обстоятельства происхождения |
| Лишение/ограничение род. прав (СК 69-73) | основания; ребенок; обязателен орган опеки |
| Раздел имущества (СК 38) | перечень со стоимостью; доля — по каждому объекту (правило CLAUDE.md) |

## §7 Общие требования и выбор кодекса

Все документы: русский язык (иное — нотариальный перевод); подпись собственноручная или УКЭП; дата обязательна; копии по числу участников + суд; приложения нумеруются в конце; идентификаторы граждан-ответчиков обязательны; эл. подача — ГАС «Правосудие» (СОЮ/КАС), «Мой арбитр» (арбитраж).

| Суд / спор | Кодекс |
|---|---|
| Районный / мировой; граждане, неэкономические | ГПК |
| Арбитраж; ИП и организации, экономические | АПК |
| Против органов власти | КАС |
| Семейные | ГПК + СК |
