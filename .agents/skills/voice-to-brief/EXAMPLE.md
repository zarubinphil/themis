# Разобранный пример

Показывает, что скилл делает с реальной расшифровкой. Взята постановка задачи
владельца от 04.08.2026, приведенная к виду, в котором приходит распознанная речь:
97 слов, ноль знаков препинания, три самоперебивания.

## Исходник (`raspoznano.md`)

```
так значит слушай по фемиде надо это доделать чтобы работало а не почти
работало вот там вердикт лежит в логах аудита по нему и иди уровни один и два
обязательно третий если время останется ну и там еще гитхаб посмотри что можно
забрать себе только код не копируй метод бери и вот еще что важно каждую правку
проверяй мутацией сломай в копии и убедись что тест покраснел иначе смысла нет
а да и самое главное персональные данные никуда не должны уйти папки с
фамилиями это тоже персональные данные ну и в конце отчет что сделал что нет
```

## Результат (`prompt.md`)

```
## ПРОМПТ ИЗ РАСШИФРОВКИ            Дата: 04.08.2026 · Исходник: raspoznano.md

ТРЕБОВАНИЯ (полный перечень, ничего не опущено)
1. Довести Фемиду до рабочего состояния — критерий владельца: «работало, а не почти работало».
2. Идти по вердикту совета: cases/_logs/audit_03-08-2026/VERDICT.md.
3. Уровни 1 и 2 вердикта — обязательны.
4. Уровень 3 — если останется время.
5. Посмотреть GitHub, забрать применимое.
6. Каждую правку проверять мутацией: сломать логику в копии, убедиться, что selftest краснеет.
7. Отчет в конце: что сделано, что нет.

ЗАПРЕТЫ (заглавными, дословно от владельца)
- КОД НЕ КОПИРОВАТЬ. Брать метод. («только код не копируй метод бери»)
- ПЕРСОНАЛЬНЫЕ ДАННЫЕ НЕ ДОЛЖНЫ УЙТИ НИКУДА.
- ИМЯ ПАПКИ С ФАМИЛИЕЙ — ТОЖЕ ПЕРСОНАЛЬНЫЕ ДАННЫЕ (то есть скрывать надо и пути).

КОНТЕКСТ (справочно, исполнению не подлежит)
- «иначе смысла нет» — довод в пользу мутационной проверки, не отдельная задача.
- «самое главное» перед запретом на ПД — приоритет, а не требование.

ВОССТАНОВЛЕНО
- «это» = проект Фемида, корень репозитория (`$THEMIZ_HOME`).
- «вердикт в логах аудита» = cases/_logs/audit_03-08-2026/VERDICT.md (на диске один).
- «уровни один и два» = разделы «Уровень 1» и «Уровень 2» раздела 4 «БЕРЕМ».

НЕ ВОССТАНОВЛЕНО
- «что можно забрать» с GitHub — перечень источников в расшифровке не назван.

РАЗВИЛКИ
РАЗВИЛКА 1. «третий если время останется»
  А: уровень 3 целиком, после уровней 1-2  → +4-6 ч работы
  Б: из уровня 3 только то, что дешевле часа → остальное в остаток
  Предлагаю Б — уровень 3 сам помечен «полезное, но не горит», а уровни 1-2
  бьют по подаваемому документу. Подтвердите либо поправьте.
РАЗВИЛКА 2. «гитхаб посмотри что можно забрать»
  А: пройти все 78 кандидатов из отчетов  → разведка на всю ночь, внедрения не будет
  Б: взять приоритетные 1-8 из задачи      → внедрение вместо перечисления
  Предлагаю Б.
РАЗВИЛКА 3. «в конце отчет»
  А: только в чат   Б: в чат и файлом
  Предлагаю Б: отчет в чате теряется вместе с сессией.

СВЕРИТЬ НА СЛУХ
- «уровни один и два» — числа названы голосом, сверить с нумерацией разделов вердикта.

ИСПОЛНЯЕМЫЙ ПРОМПТ
1. Прочитать VERDICT.md (разделы 1 и 4), report_A/B/C — детали воспроизведения.
2. Закрыть уровень 1 (пп. 1-6), затем уровень 2 (пп. 7-13). Уровень 3 — по остатку времени.
3. Каждая правка: фикс → selftest зеленый → мутация (сломать проверяемую ветвь во
   временной копии) → selftest ОБЯЗАН покраснеть. Мутация выжила = проверка не написана.
4. Проверка на живом материале дела, не на синтетике.
5. GitHub: брать наблюдение и метод, реализовывать своим кодом, источник указывать
   в шапке раздела. Построчное копирование чужого файла ЗАПРЕЩЕНО.
6. Персональные данные: cases/ и производное в публичный репозиторий не уходят;
   пути дел не печатать в выгрузках — имя папки это фамилия.
7. Отчет: что внедрено, что отклонено и почему, чем стало дешевле, что осталось.

ПРИЕМКА
- Уровни 1 и 2 закрыты, у каждой правки есть убитая мутация.
- git status чист, в публичном репозитории персональных данных ноль.
```

## Что здесь показательно

- **Требований оказалось семь, а не «сделай по вердикту».** Шесть из семи звучали
  вскользь, между делом.
- **Три запрета вынесены отдельно.** В потоке речи «только код не копируй» стоит
  придаточным внутри фразы про GitHub — при беглом чтении теряется первым.
- **«Иначе смысла нет» не стало задачей.** Это довод, а не требование: попытка
  превратить его в работу дала бы выдуманный пункт.
- **Три развилки названы, ни одна не решена молча.** Каждая меняла бы объем ночной
  работы в разы.
